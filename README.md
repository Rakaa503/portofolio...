# AVILLA.DEV Portfolio

A personal portfolio for Rakha Avilla, built with Vue 3, Vite, JavaScript, and plain CSS.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.

The application entry point is `src/main.js`. Page sections are implemented as Vue single-file components in `src/components/`, with shared styles in `src/assets/css/style.css`.
